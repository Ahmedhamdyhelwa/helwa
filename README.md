# حياتي — تطبيق إدارة الحياة الشخصية 📱

تطبيق أندرويد لإدارة المهام والتذكيرات اليومية، مكتوب بـ Kotlin و Jetpack Compose.

## المميزات
- 🏠 شاشة رئيسية بتحية شخصية وملخص مهام اليوم وأقرب تذكير
- ✅ إضافة وتعديل وحذف المهام مع أولوية وفئة وتكرار
- 🔔 تذكيرات بصوت واهتزاز تظهر على شاشة القفل، مع أزرار "تم" و"تأجيل 15 دقيقة"
- 🌅 ملخص صباحي يومي بمهام اليوم
- 🗂️ فئات ملوّنة (شخصية / عمل / صحة / تسوق / أخرى) مع فلترة
- ⚙️ إعدادات: الاسم، وقت التذكير الصباحي، الاهتزاز، الصوت، الثيم
- 🌙 ثيم فاتح / داكن / تلقائي — واجهة عربية كاملة RTL

## 📥 تنزيل التطبيق على الموبايل
1. افتح صفحة **Releases** في المستودع على GitHub من موبايلك.
2. نزّل ملف **`app-debug.apk`** من أحدث نسخة.
3. افتح الملف، واسمح بالتثبيت من "مصادر غير معروفة" لو طلب منك.
4. ثبّت التطبيق واستمتع 🎉

> ملف الـ APK بيتبني تلقائيًا على GitHub Actions بعد كل تحديث.

## 🛠️ البناء محليًا
```bash
./gradlew assembleDebug
# الملف الناتج: app/build/outputs/apk/debug/app-debug.apk
```

## البنية التقنية
- **اللغة:** Kotlin
- **الواجهة:** Jetpack Compose + Material 3
- **قاعدة البيانات:** Room
- **الإعدادات:** DataStore
- **التذكيرات:** AlarmManager + WorkManager
- **المعمارية:** MVVM + Repository Pattern
- **أقل إصدار مدعوم:** Android 8 (API 26)
